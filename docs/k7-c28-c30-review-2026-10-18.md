The allowed-type list includes `JAVA SOURCE` and `ASSEMBLY`. The current English
[Oracle 19c ALL_SOURCE reference](https://docs.oracle.com/en/database/oracle/oracle-database/19/refrn/ALL_SOURCE.html)
lists `ASSEMBLEY` and omits `JAVA SOURCE`, while an older
[Oracle 12.2 reference](https://docs.oracle.com/en/database/oracle/oracle-database/12.2/refrn/ALL_SOURCE.html)
lists `JAVA SOURCE`. This ambiguity does not affect the VIEW refusal or current K7
cases. Before claiming exhaustive 19c type support in a full qualification manifest,
verify the actual target's returned TYPE values or narrow the advertised claim; do not
silently turn the documentation discrepancy into a case-set change.

## Next assignment before another provider run

Harden only the three prototype checks with a direct general rule and useful controls:

1. **Privilege remedy alternative:** flag a synonym offered *instead of* a needed
   object privilege only when the answer/context establishes a privilege failure.
   `ORA-00942` alone is not such proof. Preserve a synonym used after a grant or for a
   missing unqualified name.
2. **Elapsed upper bound:** flag a returned idle/wait duration used as an upper bound
   on uncommitted work or transaction age; do not flag a duration used as an elapsed
   observation or an unrelated timeout. Keep numeric parsing bounded.
3. **Subprogram grouping:** compare overload counts only within the same owner/package
   and a complete, untruncated `package_subprograms` result. Group by distinct
   SUBPROGRAM_ID/OVERLOAD, not argument rows. Preserve genuine overloads and leave
   incomplete results unresolved.

integrated claim findings and revision note. **Do not integrate `read_range` yet:** it

error for grounding review; do not claim automated coverage of it.
