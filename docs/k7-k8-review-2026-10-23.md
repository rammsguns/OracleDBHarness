| Low | `services/api/harness_api/copilot/claim_checks.py:3076-3078` | Elliptical visibility patterns require `(?:this\|the)\s+account`. ## 1. Collection Declaration Contract & Service Wiring — PASS WITH FINDINGS

Inspection of `edit_contract.collection_declaration_problems` and `service.py`:
- **Correctness and Grammar Coverage:**
  - Detects inline `TABLE OF`, `VARRAY(n) OF`, `VARYING ARRAY(n) OF`, and `TABLE OF ... INDEX BY`.
  - Properly ignores valid `TYPE <name> IS TABLE OF ...`, `SUBTYPE <name> IS TABLE OF ...`, and `CREATE [OR REPLACE] TYPE <name> AS/IS ...`.
  - Tolerates multiline declarations, comments between `IS` and `TABLE OF` (e.g. `TYPE t IS /* comment */ TABLE OF ...`), and `TABLE(...)` operators in SQL queries (`SELECT * FROM TABLE(v)`).
  - Correctly strips comments and string literals via `strip_literals_and_comments`.
  - The suggested repair message correctly explains PLS-00103 and prescribes declaring the collection type first:
    `TYPE t IS TABLE OF ...; v t;`.
- **Service Wiring in `service.py`:**
  - Evaluated on first proposals alongside `anchor_problems`:
    ```python
    proposal = "\n".join(b.text for b in first.blocks)
    anchors = anchor_problems(proposal, metadata) + collection_declaration_problems(proposal)
    if anchors:
        event["anchorRepair"] = anchors
    ```
  - Dispatches `anchor_repair_message` with both anchor and collection problems listed.
  - Retried proposals are verified via `reading.delivered != "proposal" or ... or collection_declaration_problems(...)`.
  - Acceptance transitions to `repair: "repaired"` when corrected, or `repair: "failed:anchor"` when unresolved, exactly matching the anchor repair path.
- **Edge Cases Identified:**
  - Finding 6: If an inline declaration includes a default initializer (e.g. `:= t()`), `definition` captures through the trailing semicolon, generating `TYPE t IS ... := t();`.
  - Finding 7: Quoted identifiers for variables (`"l_orders" TABLE OF ...;`) are not recognized.
